# M2c: Courses as Real Maps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** faith-runner's Rooftops and greybox courses become real Unreal maps (`/Game/Runline/Maps/Rooftops`, `/Game/Runline/Maps/Greybox`), baked from the exported data by a commandlet. They are built from placeable actors you can edit in the editor, with checkpoint and finish volumes and a basic time trial. Rooftops is the map the game opens, and a test proves the baked map is bit-exact with faith-runner.

**Architecture:**
- **Three placeable actors:**
  - `ARunlineBox`: a blocking `UBoxComponent` root plus a cube mesh coloured by its look, and its level `Order`.
  - `ARunlineCheckpoint`: a trigger region, a spawn point and yaw, a name, and an index.
  - `ARunlineFinish`: a trigger region.
- **One spawn path.** `RunlineCourses::Spawn(UWorld*, const FRunlineCourseData&)` creates them from the parsed CSV. The game mode uses it when a map has no checkpoints (the M2a `?course=` path, kept for the empty map). The editor commandlet `RunlineBakeCourse` uses it to build and save a `.umap` with lights, a PlayerStart and the game mode override.
- **The runner reads the map.** It finds checkpoints and the finish by actor iteration, so a designer-edited map works with no CSV.
- **Bit-exact proof.** An editor automation test loads the baked Rooftops map and replays the 15 committed `rooftops_tests` traces on it through `FUnrealWorld`, bit-exact. A second test runs faith-runner's R1 route script through the real movement component on that map.

**Tech Stack:** UE 5.8 C++ (a new editor module, `RunlineEditor`, using UnrealEd's `UEditorLoadingAndSavingUtils`), automation tests, and Git LFS for the `.umap`s.

**Spec:** `docs/superpowers/specs/2026-10-09-faith-movement-port-design.md` (M2: "faith-runner's Rooftops map imported by script"; §4.4: "a few automation tests that load the greybox map and run scripted inputs through the real component")

**Deliberate deviation:** the spec's architecture names "Editor Python: builds levels from box lists". This plan bakes with a C++ commandlet instead. It reuses the C++ CSV parser and `RunlineUnits`, so the core-to-Unreal coordinate conversion stays in one place (spec §3), and it needs no Python or editor-scripting plugins. The result is the same: maps built by script from the box lists.

## Global Constraints

- Unit and axis conversion only in `RunlineUnits.h` (spec §3).
- Boxes keep faith-runner's level order: the `RunlineOrder<N>` component tag, which `FUnrealWorld` sorts by (M2a).
- The level CSVs (`Unreal/Runline/Data/Levels`) are generated by tools/golden. Never hand-edit them. Hand edits belong in the maps.
- Maps are Git LFS assets (`.gitattributes`: `*.umap`). Commit the baked maps.
- Credit faith-runner for the courses (CREDITS.md, done in M2a).
- Unreal at `D:\UE_5.8`. `scripts/test-unreal.ps1` and `scripts/test.ps1` stay green.
- Merging to master is the user's decision.

## Review Focus

1. **A designer edits the map.** Moving or resizing a box in the editor must change the collision the core sees: the box component is the collider, and the mesh follows it in `OnConstruction`. Test: Task 1 `Runline.Course.BoxMeshFollowsCollider`.
2. **A map with no checkpoints, or the empty map.** The game still plays: it falls back to the CSV course from `?course=` (default greybox), as in M2a. Test: Task 1 `Runline.Course.SpawnsWhenTheMapHasNone`.
3. **Re-baking over an existing map.** Running the commandlet again replaces the map cleanly, with no duplicate actors. Test: Task 2 `Runline.Bake.RebakeReplaces`.
4. **The timer.** It starts only when she leaves the start region on the ground, stops at the finish, and resets on respawning at checkpoint 0. A respawn at a later checkpoint doesn't restart it, matching faith-runner's app. Test: Task 4 `Runline.Timer.*`.
5. **The packaged game.** The Game target still compiles, and the editor module is not in it. Test: Task 2, Step 5 (build the Game target).

### Task 1: Placeable course actors, and one spawn path

**Interfaces (produces):**

```cpp
/// A level file (Data/Levels/<name>.csv), parsed. Core metres.
struct FRunlineCourseData
{
    struct FBoxEntry { runline::Aabb Box; FString Look; bool bSolid = true; int32 Order = 0; };
    struct FCheckpointEntry { FString Name; runline::Aabb Region; runline::Vec3 Spawn; float Yaw = 0.0f; };
    FString Name;
    TArray<FBoxEntry> Boxes;          // solids carry Order 0..N-1 in file order; decor Order -1
    TArray<FCheckpointEntry> Checkpoints;
    TOptional<runline::Aabb> Finish;
    int32 SkippedFixtures = 0;
    /// False (and an error logged) if the file is missing or a line can't be read.
    static bool Load(const FString& LevelName, FRunlineCourseData& Out);
};

UENUM() enum class ERunlineLook : uint8 { Roof, Wall, Runner, Prop, Finish, Skyline };

/// One box of a course: the collider the core sees (a blocking UBoxComponent, tagged with its level
/// order), and a cube coloured by its look that follows the box in OnConstruction (move or resize
/// the box in the editor and both change).
UCLASS() class ARunlineBox : public AActor {
    UPROPERTY(VisibleAnywhere) TObjectPtr<UBoxComponent> Box;
    UPROPERTY(VisibleAnywhere) TObjectPtr<UStaticMeshComponent> Mesh;
    UPROPERTY(EditAnywhere) ERunlineLook Look = ERunlineLook::Roof;
    UPROPERTY(EditAnywhere) bool bSolid = true;          // false: drawn only (decor)
    UPROPERTY(EditAnywhere) int32 Order = 0;             // faith-runner's level order (tie-breaking)
    void SetFromCore(const runline::Aabb& B);            // places the actor and sizes the box (RunlineUnits)
    runline::Aabb CoreBox() const;
    virtual void OnConstruction(const FTransform& T) override;
};
/// A checkpoint: walking into Region makes Spawn (with Yaw) the respawn point.
UCLASS() class ARunlineCheckpoint : public AActor {
    UPROPERTY(VisibleAnywhere) TObjectPtr<UBoxComponent> Region;   // no collision, query-only for editor display
    UPROPERTY(EditAnywhere) FString CheckpointName;
    UPROPERTY(EditAnywhere) int32 Index = 0;
    UPROPERTY(EditAnywhere, meta = (MakeEditWidget)) FVector SpawnPoint;   // relative to the actor
    UPROPERTY(EditAnywhere) float SpawnYawDegrees = 0.0f;                  // Unreal yaw
    runline::Aabb CoreRegion() const; runline::Vec3 CoreSpawn() const; float CoreYaw() const;
};
UCLASS() class ARunlineFinish : public AActor { UPROPERTY(VisibleAnywhere) TObjectPtr<UBoxComponent> Region; runline::Aabb CoreRegion() const; };

namespace RunlineCourses {
    /// Spawns a course's actors (and a sun, sky light and atmosphere if bLights) into World.
    void Spawn(UWorld* World, const FRunlineCourseData& Data, bool bLights);
    /// The world's checkpoints, sorted by Index.
    TArray<ARunlineCheckpoint*> Checkpoints(const UWorld* World);
    /// First checkpoint containing Feet (faith-runner's checkpoint_at), or INDEX_NONE.
    int32 CheckpointAt(const TArray<ARunlineCheckpoint*>& Cps, runline::Vec3 Feet);
}
```

/// faith-runner's app (main.rs "time trial"): the clock starts when you leave the start region
/// (checkpoint 0) on the ground, stops in the finish region, and resets when you respawn at the start.
struct FRunlineTimer
{
    TOptional<float> Running;      // seconds, while running

    void OnRespawn(int32 Checkpoint);   // checkpoint 0 clears Running
};
